# Lista de compras

Programa en Python para manejar una lista de compras desde la terminal.

## Funciones
- Agregar productos
- Ver la lista numerada
- Borrar un producto
- Avisa si la lista está vacía o si el producto no existe

## Cómo ejecutar
Necesitas Python 3.

```bash
python lista.py
```

## Lo que aprendí
- Crear y usar listas en Python
- Agregar con `append()` y borrar con `remove()`
- Saber el largo de una lista con `len()`
- Buscar un elemento con `in`
- Recorrer una lista con `for`
